# token-meter

Claude Code 프롬프트 바로 위에 **컨텍스트 사용률, 턴/세션 토큰 사용량, 사용 한도, 비용**을 한 줄로 보여주는 플러그인입니다. `/tokens` 명령으로 상세 내역도 확인할 수 있습니다.

```
컨텍스트 42% (84.2k/200k)  턴 ↑12.3k ↓850  ·  세션 ↑310k ↓9.4k  ·  5시간 24%  ·  $0.42  숨기기
```

## 설치

Claude Code에서 아래 두 명령을 실행합니다.

```
/plugin marketplace add nike2lim/token-mod-meter
/plugin install token-meter@token-meter
```

설치 후 Claude Code를 재시작하거나 새 세션을 열면 프롬프트 위에 표시줄이 나타납니다. 첫 턴이 끝나야 토큰 수치가 채워집니다.

### 업데이트 / 제거

```
/plugin marketplace update token-meter
/plugin uninstall token-meter@token-meter
```

## 표시줄 읽는 법

| 항목 | 의미 |
| --- | --- |
| `컨텍스트 42% (84.2k/200k)` | 현재 컨텍스트 창 사용률 (사용 토큰 / 전체 창). 60% 이상이면 노란색, 85% 이상이면 빨간색으로 표시 |
| `턴 ↑ ↓` | 마지막 메인 턴의 입력(↑) / 출력(↓) 토큰. 입력은 신규 + 캐시 읽기 + 캐시 쓰기 합계 |
| `세션 ↑ ↓` | 이번 세션 전체 누적 입력 / 출력 토큰 (서브에이전트 사용량 포함) |
| `5시간` · `7일` · `한도` | 사용 한도(rate limit) 소진율 |
| `$0.42` | 세션 비용 (엔진이 보고하는 경우) |
| `숨기기` | 클릭하면 표시줄을 숨김 |

## `/tokens` 명령

| 명령 | 동작 |
| --- | --- |
| `/tokens` | 컨텍스트, 마지막 턴, 세션 합계(캐시 적중률 포함), 사용 한도와 초기화 시각, 비용 상세 출력 |
| `/tokens hide` | 표시줄 숨기기 |
| `/tokens show` | 표시줄 다시 보이기 |
| `/tokens reset` | 세션 토큰 합계와 턴 수를 0으로 초기화 |

`/tokens` 출력 예시:

```
컨텍스트: 84.2k / 200k (42%)
마지막 턴: 입력 12.3k (신규 1.2k · 캐시 읽기 10.5k · 캐시 쓰기 600, 캐시 적중 85%) / 출력 850
세션 합계 (7턴, 서브에이전트 포함): 입력 310k (...) / 출력 9.4k
사용 한도 5시간: 23.5%, 초기화 ...
비용: $0.42
```

```
  hooks.json         훅 모듈 목록
  register.tsx       표시줄 렌더링, /tokens 명령, 사용량 집계

tests/               플러그인 테스트
```
